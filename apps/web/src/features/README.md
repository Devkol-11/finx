# Features

This folder contains feature-specific modules for the FINX application.

## Structure

- Each feature has its own folder containing:
  - `components/` - Feature-specific components
  - `hooks/` - Feature-specific hooks
  - `services/` - Feature-specific API services
  - `types/` - Feature-specific types
  - `index.ts` - Barrel export

## Features Include

- **Auth**: Authentication and authorization
- **Wallet**: Wallet management and transactions
- **Invest**: Investment management
- **Profile**: User profile management

## Example Structure

```
features/
  auth/
    components/
    hooks/
    services/
    types/
    index.ts
  wallet/
    components/
    hooks/
    services/
    types/
    index.ts
```
