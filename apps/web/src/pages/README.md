# Pages

This folder contains page components that map to routes.

## Structure

- Each page is a top-level component
- Pages compose features and other components
- Pages handle routing and layout

## Example Pages

- `Home.tsx` - Home/Dashboard page
- `Login.tsx` - Login page
- `Register.tsx` - Registration page
- `Investments.tsx` - Investments page
- `Wallet.tsx` - Wallet management page
